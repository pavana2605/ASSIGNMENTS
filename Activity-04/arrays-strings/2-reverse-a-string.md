## Problem: Reverse a String (Easy)

**Link:** https://leetcode.com/problems/reverse-string/

### Approach

I used a two-pointer approach by swapping characters from the beginning and end of the string. The pointers move toward the center until the complete string is reversed.

### Complexity

- Time: O(n)
- Space: O(1)

### Notes

The string is reversed in place without creating another string. A single-character string remains unchanged.
